# Work with HQBot

Start with **Conversations**. Choose a teammate, describe the result you need, and let it work.
The computer panel is visible beside the conversation on desktop. Use **Computer** in the
conversation header to open it again, or to show it on a phone. Stop remains available during
work. Teammates run in Cloudflare when you close the page.

- **Inbox** holds replies, completed work, failures, and requests for a decision. Enable notifications
  under Devices if you want an alert while the browser is closed.
- **Library** holds each teammate's memory and skills. Edit a memory, inspect its history, or forget
  it. Skills can start as drafts. Record a demonstration, select useful frames, and review the
  generated steps before marking the method ready.
- **Projects** give selected teammates a shared purpose and selected resources. Use a group
  conversation to address one or more teammates. Replies keep their context in threads.
- **Automations** runs work at an interval, on chosen days in a time zone, or after a signed event.
  Test a routine now, inspect its history, or pause it. The event setup supports GitHub, Slack,
  and signed generic webhooks.
- **Search** finds conversations and saved work. Use Cmd+K on Mac or Ctrl+K elsewhere. Search results
  can open the source or prepare a conversation draft.
- **Settings** contains teammate controls, people, network policy, and devices. Invite people to
  projects with their own accounts. A project's members can read the full history and files of its
  teammates, so use separate teammates for confidential projects.

Most work can continue without a prompt after you give the teammate a clear task and suitable
permissions. A tool approval is for an action that needs review, such as sending a message through
a newly connected service. You can add an exact, scoped allow rule for a repeated action. Rules
can expire or apply to one task. A server's claim that a tool is read-only does not grant access.
A local command always asks in the Mac companion because it runs with your Mac account.

In **Library → Templates**, copy selected skills and routines into a reusable teammate. Imports
start with draft skills and paused routines. Review the whole template before publishing a public
link. Templates do not include memory, files, connections, or credentials. Revoke a link to stop
future downloads; a copy already downloaded stays with its recipient.

Install the web app from your browser, or build the [native clients](../clients/README.md). The web
app uses an offline page when disconnected; it does not cache conversations or files for offline
reading. Server work continues. Push and screen recording need a supported browser.
