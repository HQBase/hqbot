# Teach a skill with a recording

In **Library**, choose a teammate and select **Record a skill**. Enter a name and describe the
goal, important inputs, and how to check the result. Use a name that is not already in its library.

Select **Start recording** and choose a window or screen in the browser's picker. Audio is off.
Show the workflow. HQBot captures a key frame every ten seconds; use **Capture key step** for an
important step between those frames. Select **Stop recording** when finished. The recorder stops
automatically at ten minutes or about 9 MB.

Review the video and select up to twelve frames. Frames from the beginning and end are selected
automatically when a recording is long. Remove any frame with private information. The full video
will also be saved, so discard and record again if it contains information you do not want stored.
Close the dialog to discard a recording before upload.

Select **Save and create draft**. HQBot saves the video and selected images as private teammate
files. It queues a vision-model review using the teammate's budget. The review receives your notes
and selected frames, not every moment of the video. It has no tools and does not perform the
demonstrated actions. It keeps unclear or unseen steps as items for review.

**Recorded demonstrations** shows progress. Select **Review draft** when ready. Check the method,
correct missing steps, and test it with safe inputs before making the skill ready. Draft skills
do not appear in the agent's ready skill list. Source files remain available in Files. Delete the
recording to remove its generation record; remove the generated skill separately when no longer
needed. Stop or archive the teammate to cancel unfinished draft generation.

Screen capture needs a supported desktop browser and screen-recording permission. Mobile devices
can review and edit saved skills. Actual capture availability depends on the browser and device.
