# Teammate templates

Open **New conversation → Use a template**. Choose a teammate, then select the skills and routines to include.
Select **Review and copy** to inspect the profile and full instructions.

- **Create teammate** makes a separate teammate. Its skills start as drafts and its routines are paused.
- **Download** saves a portable JSON file. Another HQBot owner can import it from the same page.
- **Publish public link** shares the reviewed copy. Anyone with the link can read and download it.

Templates do not copy history, memory, files, connections, credentials, device pairing, permission
grants, or event triggers. The selected instructions can still contain private information. Check
them before sharing. Imported methods need review and testing in their new workspace.

The public link stays fixed if you later edit the original teammate. Select **Revoke link** to stop
future downloads. Copies that someone already downloaded cannot be recalled.

An import can contain at most 30 skills, 20 routines, and 80 KB in total. Resource names must be
distinct. A retry of the same import request creates only one teammate. A deleted imported teammate
is not recreated by a late retry.
